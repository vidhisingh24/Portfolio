# Vidhi Singh — Portfolio

**Live site: [vidhisingh-portfolio.vercel.app](https://vidhisingh-portfolio.vercel.app)**

[![Visit the portfolio](https://img.shields.io/badge/Visit-vidhisingh--portfolio.vercel.app-7C3AED?style=for-the-badge&logo=vercel&logoColor=white)](https://vidhisingh-portfolio.vercel.app)

My personal site: projects, skills, open-source programs and how to reach me.

## Stack

- React 19 + Vite
- Tailwind CSS v4
- Framer Motion, cmdk (⌘K / Ctrl+K command menu), Lenis
- Deployed on Vercel; the hero is pre-rendered to static HTML at build time

## Editing content

All text lives in typed data files under `src/data/`:

| File | What it holds |
| --- | --- |
| `profile.ts` | Name, links, hero, about, contact |
| `now.ts` | The "Now" card under the hero |
| `projects.ts` | Project cards and case studies |
| `skills.ts` | Skill groups |
| `openSource.ts` | GSSoC, SSoC, OSCI |
| `timeline.ts` | Journey, learning path, achievements |
| `bot.ts` | VidhiBot answers |

Any value starting with `TODO` is hidden on the site until it is filled in.

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
npm run preview  # serve the build
```
